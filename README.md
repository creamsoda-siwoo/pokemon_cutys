# 포켓몬 모험 RPG

파트너 포켓몬과 함께 5개의 지역을 돌파하는 로그라이크 RPG입니다. (Next.js)

## 실행

```bash
npm install
npm run dev      # http://localhost:3000
```

배포용 빌드는 `npm run build && npm start`.

🌐 **바로 플레이: https://pokemon-cutys.vercel.app** (`main`에 올리면 Vercel이 자동 배포)

## 게임 소개

- **파트너 선택**: 이상해씨 · 파이리 · 꼬부기 · 피카츄 중 하나로 시작
- **난이도**: 🌱 쉬움 · ⚔️ 보통 · 🔥 어려움 (어려움은 골드 1.5배)
- **🌟 색이 다른 포켓몬**: 야생에서 5% 확률로 등장, 능력치 10% 보너스, 이기면 반드시 동료가 됨
- **지역 탐험**: 초록빛 숲 → 반짝이는 호수 → 으스스한 동굴 → 불타는 화산 → 최후의 탑
  - 층마다 갈 곳을 선택: ⚔️ 야생 배틀 · 💀 강적 · ⛺ 캠프 · 🛒 상점 · 🎁 이벤트, 마지막 층은 👑 보스
- **턴제 배틀**: 9가지 타입 상성, 급소, 화상/마비, 공격·방어 강화, 회복 기술
- **성장**: 레벨업으로 새 기술 습득, 레벨이 차면 **진화** 연출 (이브이는 Lv.10에 샤미드·쥬피썬더·부스터·에브이·블래키 중 선택!)
- **효과음**: 8비트 효과음 (오른쪽 위 🔊 버튼으로 끄기)
- **📊 상성표**: 오른쪽 위 버튼으로 타입 상성 확인
- **동료 영입**: 배틀 후 동료가 되고 싶어 하거나, 몬스터볼로 포획 (파티 최대 4마리)
- **도감**: 만난 포켓몬이 기록되어 다음 모험에도 남음
- **🏅 업적 19개**: 첫 승리, 진화, 보스 격파, 라이벌, 진화의 돌, 어려움 클리어, 무한의 탑 등
- **💎 진화의 돌**: 불꽃·물·천둥·리프의 돌 (상점·이벤트·라이벌 보상). 이브이→부스터/샤미드/쥬피썬더, 피카츄→라이츄, 식스테일→나인테일, 가디→윈디, 냄새꼬→라플레시아
- **🧢 라이벌 하늘**: 3층부터 등장하는 트레이너 배틀. 내 스타터에게 강한 타입의 파트너와 2~3마리 팀으로 승부, 이기면 진화의 돌
- **♾️ 무한의 탑**: 뮤츠를 쓰러뜨린 뒤 같은 파티로 계속 도전, 구역마다 적이 강해짐
- **🔊 울음소리**: 포켓몬이 나타나거나 동료·진화할 때 진짜 울음소리 재생 (PokeAPI cries)
- **📋 포켓몬 정보**: 파티의 포켓몬을 누르면 능력치·기술·진화 단계 확인

다른 미니게임: `/catch.html` (포켓볼 던지기), `/memory.html` (짝맞추기)

포켓몬 이미지는 [PokeAPI sprites](https://github.com/PokeAPI/sprites)의 공식 일러스트를 불러옵니다 (인터넷 연결 필요).

## 구조

- `lib/data.ts` – 타입 상성, 기술, 포켓몬, 지역, 아이템 데이터
- `lib/engine.ts` – 능력치, 데미지 계산, 레벨업/진화, 적 AI
- `lib/sound.ts` – Web Audio 효과음
- `components/Game.tsx` – 화면 흐름과 전투 UI
- `scripts/sim.ts` – 밸런스 확인용 시뮬레이션 (`npx tsx scripts/sim.ts`)
